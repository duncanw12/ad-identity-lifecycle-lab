# Live Lab Output

This directory contains output generated by the running `lab.local` Active Directory environment.

## Files

### `access-report.csv`
Generated by:

```powershell
Get-LabAccessReport
```

The report captures account state, role, creation date, last logon, group membership, and the 30-day stale-account flag.

### `lifecycle.log`
Audit trail generated by the lifecycle automation. It records lab structure creation, user creation, password-reset tickets, offboarding, and access-report generation.

Temporary passwords are intentionally not written to this log.
